MOTIVATE - INFO PAGE

Scroll with the mouse wheel, the scroll bar, or the arrow / Page Up / Page Down / Home / End keys. Any other key or a click closes this page.

PURPOSE

  • MOTIVATE is a set of full-screen trading motivation pages (rules, principles, and reminders) to keep in view during the trading session.
  • Each page is its own HTML file in the site folder; the home page has a box for every page.
  • The PAGE BUILDER creates and edits pages from a form, without editing any HTML.
  • To start the PAGE BUILDER press the bottom-left A button. The A button is only activated on the local website.
  • Website: jeromecharlesrenard-collab.github.io/motivate_webpage (updated after every page builder CREATE or SAVE).

HOW TO USE

  • Launch: double-click the MOTIVATE shortcut. The home page opens in your default web browser.
  • Home page: click a box (e.g. 1 - KEY POINTS) to open that page.
  • Menu (top left): opens the page list; the current page has a gray band. Esc or a click outside the menu closes it.
  • Arrows next to the menu: previous / next page (wraps around). The Left and Right arrow keys do the same.
  • Page number: the small number under the menu.
  • A (black circle, bottom left): opens the PAGE BUILDER. Not shown on the Internet website - Local website only.
  • I (black circle, bottom right): opens this info page.

PAGE BUILDER

Modes

  • New Page: creates a page. Page Number is where it goes; the pages from that number on move up by one (files, menu, home boxes, page numbers, and links are all updated). The default is the page after the one you came from.
  • Edit Existing Page: enter the Page to Edit and click LOAD (or press Enter); the name, alignment, and all lines of that page fill the form. The page keeps its number; a new name renames its file, menu entry, and home box.

Page Settings

  • Page Name: shown in the menu and on the home page box.
  • Horizontal Align: Center, Left, or Right, with an indent for Left / Right.
  • Vertical Align: Middle, Top, or Bottom, with an indent for Top / Bottom.
  • Sizes, indents, and spacing are in rem (1 rem is about the height of normal text).

Lines (20 max)

  • Each line: text, font, font size, font type (Normal, Bold, Italic, Bold Italic), font color, and spacing after.
  • Line Text grows downward while selected, so the whole text can be read and edited; it goes back to one line when you click elsewhere. Enter adds no line break (use <br>).
  • + adds a line below (copying its style), x deletes the line, ADD LINE adds one at the end. Empty lines are skipped.

Line Text: <br> and &nbsp;

  • <br> starts a new line within the same line's text, with the same font, size and color.
  • &nbsp; is a space that never disappears and never lets the line wrap at that point.
  • A line with only &nbsp; (or only <br>) is a blank spacer line.
  • Other tags kept: <strong>bold</strong>, <em>italic</em>, <u>underline</u>.

Buttons

  • PREVIEW: opens the page in its own tab without saving.
  • CREATE (new) / SAVE (edit): saves the page, uploads it to GitHub (an OK notice shows the result), then opens it. The website updates about a minute later.
  • RESET: clears the form (new) or reloads the page as saved (edit).
  • EXIT: goes back. A new-page form is remembered until CREATE or RESET.
  • Before every CREATE or SAVE, the whole site is backed up to assets\archives\saved\site_backup_<date_time>.zip.
  • The builder works only when MOTIVATE is opened with its shortcut (it needs the local MOTIVATE server).

THIS INFO PAGE

  • Edit in Word: assets\MOTIVATE_info_page.docx is the master copy. Edit and save it; the next click on I (or the next MOTIVATE start) rebuilds this page and uploads it to the website.
  • Section titles: bold 14 pt paragraphs. Sub-titles: bold 12 pt paragraphs. Bullets, numbered lists, bold, italic, and underline carry over; font sizes on this page are set by the page itself.

OPTIONS (config.json)

  • start_page: the page the shortcut opens (default index.html, e.g. 01_key_points.html).
  • log_level: INFO (default) or DEBUG. The log is in logs\app.log (EDT times).
  • port: local server port (default 8765).
  • idle_minutes: the server stops after this long with no page open (default 120); double-click the shortcut again to restart it.
  • auto_upload: true (default) uploads every CREATE / SAVE and info page change to GitHub; false keeps changes on this PC only.
